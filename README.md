# 0g

General-purpose personal repo for notes, experiments, and small projects.

## What goes here

- Notes and write-ups in markdown
- Quick scripts and throwaway experiments
- Small projects that don't need their own repo yet

## Suggested layout

These folders are suggestions, not rules. Create them as needed.

- `notes/` for markdown notes
- `experiments/` for throwaway scripts and tests
- `projects/` for anything that grows past a single file

Anything that outgrows this repo gets moved to its own repo.
